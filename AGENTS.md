# AGENTS.md

This file is for coding agents that change fnv-mcp itself. The rules are in [CLAUDE.md](CLAUDE.md): read it first
and follow it. It covers where to push, how to run the tests, how to test against the running game, and the engine
facts some tools rely on. The documentation index is [bridge/docs/README.md](bridge/docs/README.md).

If you are an agent *using* the tools to build a mod, this is not your file: read
[bridge/docs/AGENT-GUIDE.md](bridge/docs/AGENT-GUIDE.md), and call `fnv_status` and `fnv_guide` from the server.
